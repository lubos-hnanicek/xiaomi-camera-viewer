## What's new

- Add **Help -> Check for updates...** for user-initiated stable-release checks.
- Show the available version and full changelog before asking permission to download.
- Show download progress and allow cancellation before installation.
- Verify the release package with GitHub's SHA-256 digest, expected version and
  processor architecture before using it.
- Install through a dedicated `XiaomiViewerUpdater.exe`, requesting administrator
  approval only when the application folder is not writable.
- Preserve account settings, recordings and unrelated files; restore the previous
  application files if installation fails.
- Wait for the old viewer and updater to exit using inherited process handles
  before replacing or cleaning up update files.

Full changelog: [v0.7.10...v0.7.11](https://github.com/lubos-hnanicek/xiaomi-camera-viewer/compare/v0.7.10...v0.7.11)
